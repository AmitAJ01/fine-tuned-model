## 5. Remaining Limitations

1. **Next.js Security Advisory:** Next.js version `14.1.4` has a published security advisory from December 2025. It is recommended to bump `next` to the latest `14.2.x` release in a future routine dependency maintenance pass.
2. **Local Port Accessibility:** In restricted sandbox environments, the web server is isolated. Running the live dashboard for interactive browser sessions requires starting the server outside the sandbox (`BypassSandbox: true`).
3. **Inference Backend Requirement:** Real-time GPU inference in the dashboard requires the FastAPI backend running on port 8000 with the adapter checkpoint present on disk (or setting `mock=True` / baseline mode).
